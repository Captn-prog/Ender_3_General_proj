# Ender 3 Project
Catalog of all additions and mods I have made to my personal 3D printer.

## Current Modifications and Additions
- KevinAkaSam's Belted Z mod
- Power supply re-orientation
- Sherpa Micro Extruder
- Volcano V6 hotend Clone
- Klipper Firmware Installation
- BigTreeTech SKR 1.4turbo board
- 3D touch probe

- Change the routing of cables
- Enclose printer base
- Add additional cooling fans for mainboard and raspberrypi
